# Pick and Place in MuJoCo with Inverse Kinematics

Tutorial 4 implementation for the Franka Emika Panda robot.

## Methods

- **Mink** — off-the-shelf QP-based IK (baseline)
- **DLS-IK** — closed-form damped least squares
- **QP-IK** — custom quadratic program with joint-limit constraints
